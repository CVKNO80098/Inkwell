# 欢迎使用 Inkwell

Inkwell 是一个**轻量、离线、原生**的 Markdown 写作工具。没有账号，没有云端，没有订阅——只有一张安静的纸。

> 写作不是把字填进表格，而是把想法放到纸上，让它们自己站住。

## 它适合谁

- 想要 *Typora 式* 所见即所得，却不想为订阅付费的人
- 需要 **专注** 的长文写作者、日记作者、笔记整理者
- 喜欢把文件留在自己硬盘上的人

## 核心能力

1. 实时 Markdown 语法着色，标记符号自然淡出
2. 分栏 / 仅编辑 / 仅预览三种视图
3. 侧边栏文件树与文档大纲
4. 查找替换、自动保存、崩溃恢复
5. 导出 HTML、打印 / 导出 PDF

### 任务清单

- [x] 所见即所得的编辑体验

### 代码

```csharp
public static void Main()
{
    var app = new Inkwell.App();
    app.Run(); // 一切从这里开始
}
```

### 表格

| 功能 | 快捷键 | 说明 |
| --- | :---: | --- |
| 加粗 | Ctrl + B | 包裹 ** 标记 |
| 斜体 | Ctrl + I | 包裹 * 标记 |
| 行内代码 | Ctrl + E | 包裹反引号 |
| 查找 | Ctrl + F | 当前文档内查找 |

---

## 开始写作

按下 `Ctrl + N` 新建文档，或把 Markdown 文件拖进窗口。你的文件始终在本地，`Ctrl + S` 保存。

==高亮==、~~删除线~~、[链接](https://example.com) 都能正常使用。
